# Dymension 地址列表文件示例
# 
# 文件格式说明：
# - 每行一个地址
# - 支持 EVM 地址（0x...）或 Dymension Bech32 地址（dym1...）
# - 以 # 开头的行会被视为注释，自动忽略
# - 空行会被自动忽略
# - 地址前后可以有空格，会自动去除
